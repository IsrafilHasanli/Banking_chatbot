# API Reference

This document summarizes the public HTTP endpoints exposed by the FastAPI application. Interactive OpenAPI documentation is available at `/docs` when the backend is running.

## Authentication

Protected endpoints require:

```http
Authorization: Bearer <access_token>
```

The token source depends on `AUTH_PROVIDER`:

- `postgres`: tokens are generated by the application.
- `aws`: tokens are returned by AWS Cognito.

## Endpoints

### Register User

```http
POST /auth/signup
```

Request:

```json
{
  "email": "user@example.com",
  "password": "change_me",
  "firstname": "Ada",
  "surname": "Lovelace",
  "birth_date": "1990-01-01",
  "phone_number": "+994501234567"
}
```

Response:

```json
{
  "id": 1,
  "cognito_id": "generated-or-provider-id",
  "email": "user@example.com",
  "firstname": "Ada",
  "surname": "Lovelace",
  "birth_date": "1990-01-01",
  "signup_date": "2026-09-22",
  "phone_number": "+994501234567"
}
```

### Login

```http
POST /auth/login
```

Request:

```json
{
  "email": "user@example.com",
  "password": "change_me"
}
```

Local auth response:

```json
{
  "access_token": "<jwt>",
  "refresh_token": "<jwt>",
  "token_type": "bearer"
}
```

AWS auth returns the Cognito `AuthenticationResult` payload.

### Confirm Signup

```http
POST /auth/confirm
```

Used for AWS Cognito signup confirmation. In local PostgreSQL auth mode, confirmation is not required.

Request:

```json
{
  "email": "user@example.com",
  "code": "123456"
}
```

### Chat

```http
POST /chat
```

Protected: yes

Request body:

```json
{
  "message": "What are the current card fees?"
}
```

The endpoint also accepts `message` as a query parameter.

Response:

```json
"Assistant response text"
```

The agent may answer directly, use RAG retrieval, or call a user-scoped banking tool depending on the message.

### Current Profile

```http
GET /Profile/
```

Protected: yes

Returns the authenticated user record.

### Create Account

```http
POST /product/create-account
```

Protected: yes

Request:

```json
{
  "account_type": "CURRENT",
  "currency": "AZN"
}
```

Response:

```json
{
  "account_id": 1,
  "account_number": "1234567890123456",
  "owner_id": 1,
  "account_type": "CURRENT",
  "currency": "AZN",
  "balance": 0,
  "creation_date": "2026-09-22",
  "status": "ACTIVE"
}
```

### UI Redirect

```http
GET /
```

Redirects to `/ui`.

## Error Handling

The API uses standard HTTP status codes:

- `401`: missing or invalid authentication
- `404`: authenticated user not found
- `409`: duplicate signup email in local auth mode
- `422`: invalid or missing request data
- `500`: unexpected server-side failure

Avoid returning stack traces or provider secrets in API responses.
